## 🛠️ Tech Stack & Architecture

- **Frontend & UI:** HTML5, CSS3, Modern JavaScript (ES6+), Vanilla CSS (Custom Design System & Tokens)
- **Typography:** Inter, JetBrains Mono
- **Key Modules:**
  - **Command Palette (`Ctrl+K` / `⌘K`):** Hotkey navigation modal for instant section jumping
  - **Live Timezone Engine:** Real-time Kathmandu time tracking (`NPT UTC+5:45`)
  - **Interactive Lightbox & Modals:** Dynamic project spec inspection & achievement image expansion
  - **Filter Engine:** Dynamic category filtering for products and achievements
- **SEO & Compliance:** JSON-LD Multi-Schema (Person, WebSite, ProfilePage, ItemList), Open Graph, Dublin Core, Sitemap XML, robots.txt

## 💻 Local Setup & Execution

1. **Clone the repository:**
   ```bash
   git clone https://github.com/RAUNAK-733/portfolio.git
   cd portfolio
   ```

2. **Serve locally:**
   ```bash
   npx serve .
   ```
   Or open `index.html` directly in your browser.
